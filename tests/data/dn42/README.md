# DN42 lookup fixtures

Synthetic IPv4 and IPv6 release bundle from
[DN42-IPDB-SDK](https://github.com/bird-chinese-community/DN42-IPDB-SDK/tree/bd81cf184d0470b476858e36802bca341c1c325c/testdata).
The records describe `172.20.0.0/24` and `fd42:1234::/48`, ASN 4242420001,
and host-specific PTR observations at `172.20.0.1` and `fd42:1234::1`.

The source license is in `LICENSE-SDK`; ISO name data attribution is in
`LICENSE-Unicode.txt`. These records are test data, not live network observations.
