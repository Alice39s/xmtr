# Install xmtr with OpenWrt opkg and APK v3

OpenWrt 24.10 and 25.12 receive native packages and signed repositories for eight package architectures, including MIPS in both byte orders and ARM soft-float. Release builds wait for trusted package installation and IPv4/IPv6 tracing tests in the matching OpenWrt userlands and official kernel virtual machines. ([#39](https://github.com/Alice39s/xmtr/pull/39), fixes [#37](https://github.com/Alice39s/xmtr/issues/37))
