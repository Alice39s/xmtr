# Delete uploaded traces with their admin key

An upload could not be removed, and finding an older link meant searching the terminal history. When the gateway returns an admin key with the upload, xmtr prints an admin link and a `curl -X DELETE` command under the IPMap link, in the result panel or below it when they do not fit, and in the plain output. Every upload is added to a list in the user's data directory, readable only by its owner on Unix. `xmtr traces` lists the uploads newest first, `--json` prints the complete records, and `xmtr traces delete` deletes a trace given by its ID, IPMap link or admin link from the gateway and from the list. ([#40](https://github.com/Alice39s/xmtr/issues/40))
